Three ways to put it to work

From “look at this”
to “here it is.”

01

Give your next demo a proper stage.

Capture an iPhone or iPad through USB or the wireless receiver, or choose a Mac window or screen. Record first, then compose the result.

  • Record the original in H.264 or HEVC MOV
  • Add a background, frame and time trim on export
  • Keep source audio when available

Original recordings and composed exports are separate steps.

02

Make the problem easier to understand.

Put steps, expected behavior and the actual result beside an annotated screenshot. Export one folder with Markdown, JSON and image attachments.

  • Annotate and extract text with local OCR
  • Draw opaque masks or review OCR suggestions
  • Unmasked originals are excluded by default

Review report text and attachments before sharing. Detection can miss sensitive details.

03

One composition. More places to share it.

Prepare portrait, square and landscape assets together, with a cover and a file manifest. Save a style to make the next export feel consistent.

  • 9:16, 1:1 and 16:9 image or video packages
  • A cover with an optional title
  • Reusable backgrounds, framing and orientation

Video presets: 1080 × 1920, 1080 × 1080 and 1920 × 1080.

Before you ask

The useful details.

Can I download it now?+

This is a preview. A free release is being prepared; there is no public app download yet. Release review and further physical-device testing are still in progress.

Which systems does it support?+

The current target is macOS 14 or later on Apple Silicon. The app captures iPhone, iPad and Mac sources. There are no Windows or Linux versions. The current app interface is in Italian.

Does my content go to a cloud service?+

Capture, OCR and composition run locally on your Mac, without an app account. This website has no analytics, advertising, remote fonts or third-party embeds. GitHub hosts it and handles ordinary request data.

Can I edit the recording as I capture?+

The app records the source first. You then open the video composition tool to add framing, backgrounds, trim and fixed privacy masks. Composed video exports use H.264.

What is still being checked?+

More tests with physical devices, long sessions and first launch on another Mac are pending. The current local build is not notarized. Code and asset provenance, name availability and distribution rights also need review before an app release.

How can I share feedback?+

Use the public website repository for suggestions about the project and its presentation. Do not include personal data or private recordings in a public issue.
