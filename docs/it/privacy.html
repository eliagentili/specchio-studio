Privacy, con semplicità.

Questo sito statico non utilizza analytics, pubblicità, cookie di tracciamento, contenuti incorporati di terzi o font caricati da servizi esterni. Tutte le risorse provengono dallo stesso sito GitHub Pages. Gli esempi interattivi funzionano nel browser e non inviano il loro stato a un server.

Il sito è ospitato da GitHub Pages. GitHub può elaborare informazioni delle richieste, come indirizzi IP e dettagli del browser, secondo la propria informativa. Aprendo un link GitHub accedi a un servizio separato con le proprie regole.
