SPECCHIO STUDIO — BUILD AND USER GUIDE
Mac Apple Silicon · macOS 14 or later
Updated on 18 October 2026

Published preview: 1.3.1, build 7 (v1.3.1-preview.1).
Development: 1.4.0, build 8, with English and Italian app localization.
Validation and publication of the development build are still in progress.

STARTING AND BUILDING
From this directory, run ./build.sh and open “Specchio Studio.app”.
Apple Command Line Tools, Swift, Clang and Python 3 are required. Native
dependencies are included; Homebrew is not required. To rebuild OpenSSL
as well, first run ./Native/build_crypto.sh; Perl and make are also needed.
The local app is signed ad hoc, without Developer ID signing or notarization.
The geometric icon is generated from the included code: to reproduce it,
run swift scripts/generate_icon.swift from the project directory.
The free public pre-release v1.3.1-preview.1 is experimental.
Download, corresponding source and checksums:
https://github.com/eliagentili/specchio-studio/releases/tag/v1.3.1-preview.1
Gatekeeper assessment rejects this build: it is not a notarized distribution.
Read the limitations and uncertainties in the notes before downloading it.

APP LANGUAGE
The 1.4 development build offers English and Italian. English is the default;
choose Italian or the system language through the app’s Language settings.
Quit and reopen the app to apply a language change. Changing the
preference does not interrupt active capture or exports.
Public documentation and the website are in English. The published 1.3.1
preview predates this localization work.

CONNECTING A SOURCE
USB: connect an iPhone or iPad using a data cable, unlock it and trust the Mac.
Choose Detect USB, select the device, then Connect. Camera is the permission
macOS uses for this source; Microphone access may be requested for audio.
If the source is busy, close other capture apps.

Wireless: choose Wireless. On your device, open Control Center →
Screen Mirroring → Specchio Studio; enter the code shown in the app when
prompted. Use the same Wi-Fi network for the first test. Choose the name
Specchio Studio, rather than the receiver built into your Mac.
Video appears in the Studio window. To finish, stop mirroring on the device
or choose Disconnect. After a stream ends, the receiver may keep waiting
for the next connection.
Only one window per process can activate the wireless receiver.

Window / screen: use the native macOS picker to capture another window
or a display. Allow Screen Recording access when prompted.
You can open additional app windows from the File menu; operation with
multiple devices at once still requires hardware testing.

RECORDING AND COMPOSING
Record saves the original stream as H.264 or HEVC MOV. Choose the quality
and countdown before starting. Audio is included when the source provides
it and permissions allow it; it is optional for Window / screen capture.
Captured audio is not played back live.

The app attempts to finalize a recording on stop, disconnection, end of
stream or closing. A resolution change ends the current file. Hardware
tests documented in VALIDAZIONE.txt date from 17 October 2026 and do not
replace validation of the current build.

To apply a background, frame, rotation and horizontal flip to a clip, use
Frame video after recording, or Frame in the Library. You can choose a local
video file, a time range and an output format. End = 0 exports to the end.
Output is H.264 MOV with audio from the source file when present. Export
can be canceled. The video panel previews the original file; the composition
is applied when exporting.

SCREENSHOT AND VIDEO FORMATS
Choose Format in the Composition panel. The same choice appears as Output
format in Frame video:
• Automatic: screenshots use the preview area’s proportions, with a base
  width of 1000 pixels; videos use the source proportions with room for
  the frame and background, up to 1920 pixels per side.
• Portrait 9:16: base size 1080×1920 pixels.
• Square 1:1: base size 1080×1080 pixels.
• Landscape 16:9: base size 1920×1080 pixels.
The three video presets use these exact dimensions. For screenshots, these
are the dimensions at Export scale 1×; 2× and 3× multiply them. Content is
fitted inside the composition, and empty areas use the selected background.
Preview zoom applies to screenshots, not videos.

SCREENSHOTS, ANNOTATIONS AND OCR
Save an original frame or the composition as PNG/JPEG. For transparency,
choose PNG and the Transparent background. Freeze a frame or import an
image to annotate it and undo strokes. Annotations are available in
screenshots, not exported videos. Copy text with OCR uses Vision on your
Mac and places recognized text on the clipboard. The demo is an illustration
and does not represent a connection to a real device. Anteprima-demo.png
was regenerated from the included canvas: ./test.sh produces the related
image at .build/test-results/demo.png.

LIBRARY AND PRIVACY
The Library shows recent captures and lets you open them, reveal them in
Finder or share them. Images, video and OCR are processed on your Mac.
The app does not require an account or cloud services. Pairing keys are
stored in the app’s local data, outside the repository. Saved files may
contain personal data: review them before sharing.

LIMITATIONS
Mouse/keyboard remote control, live audio monitoring, multiclip editing
and video export with an alpha channel are not implemented.
The Transparent background becomes black in H.264 videos. Protected content
may not be capturable. The app is built for Apple Silicon.
A physical iPad, long sessions, multiple devices and physical orientation
changes during recording remain untested on the current build.

VALIDATION
./test.sh runs native and Swift tests with synthetic fixtures. Results
are written to .build/test-results. ./test.sh --build-only compiles without
running tests. A restricted environment may prevent access to macOS codec
services; run the full tests in a Terminal with access to local services.
VALIDAZIONE.txt separates current results from earlier hardware reports.

1.3 WORKFLOWS
Redact data: freeze a frame and draw opaque areas. Local detection suggests
email addresses, phone numbers and possible keys: review and confirm areas.
Create bug report: enter a description, steps and outcome; choose a folder.
Screenshots, annotations, sanitized OCR and reports are saved. The unredacted
original is included only when the dedicated option is enabled.
Creator pack: three aspect ratios plus a cover with an optional title,
for images and videos. Styles save and reapply only composition appearance.
In videos, masks stay fixed for the whole clip and do not track movement.
Audio, original recordings and manually entered report fields are not redacted.
